AI security researcher · MCP ecosystem · founder, Cognivators

I research security in the Model Context Protocol (MCP) ecosystem — the emerging standard connecting AI agents to tools, data, and each other. I discovered and reported CVE-2026-14540, a Server-Side Request Forgery vulnerability in Google's MCP Toolbox for Databases (CVSS v4.0 score 8.0, High), assigned by Google as the CVE Numbering Authority. I also maintain mcp-safeguard, an open-source static-analysis scanner for MCP server security issues, and run a broader responsible-disclosure effort across MCP servers built by companies across the ecosystem.

Outside of security research, I founded Cognivators, an AI automation studio building infrastructure and tooling for service businesses.
